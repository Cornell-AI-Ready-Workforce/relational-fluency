# Personas

One file per persona: who the agent is within a scenario (name, role, disposition,
communication style, conflict behavior). Personas pair with scenario configs from
`reddit-analysis/scenarios/`.

Suggested format: YAML or JSON, e.g.

```yaml
id: defensive-coworker
name: Sam
role: coworker on the participant's project team
disposition: feels criticized, initially defensive
style: short sentences, deflects blame early, warms up if treated with empathy
```
